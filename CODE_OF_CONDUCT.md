# Code of conduct

This is a small privacy project. Be decent.

- Do not file issues that include a real vault, passphrase, mailbox password, or live identity dump.
- Do not open PRs that scrape people, bypass captchas by default, or ship exploit PoCs.
- Disagreement about catalog entries is fine; insults are not.

If someone is being abusive, open a private report from the Security tab or email the maintainer listed on the GitHub profile. Maintainers may refuse, edit, or close contributions that ignore this.
